# Painel Expresso — proposta de site

Proposta de site desenvolvida pela Agência N4 para a Painel Expresso.

## Páginas

- `index.html`: Home
- `backdrop-em-tecido.html`: página de produto do Backdrop em tecido
- `guia-tamanho-de-backdrop.html`: guia "Qual tamanho de backdrop escolher?"

HTML e CSS puros, sem build. Fontes Fredoka e Nunito via Google Fonts.

## Publicar no GitHub Pages

1. Suba o conteúdo desta pasta na raiz de um repositório.
2. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O site fica em `https://<usuario>.github.io/<repositorio>/`.

## Observações

- As fotos são capturas do Instagram @painelexpresso (720 px de largura). Para publicar como site oficial, trocar pelos arquivos originais e confirmar autorização das marcas que aparecem.
- A logo é um recorte da foto de perfil. Trocar pelo vetor oficial.
- Os botões de WhatsApp ainda apontam para âncoras da página; na versão final viram links `https://wa.me/55...` com mensagem preenchida.
